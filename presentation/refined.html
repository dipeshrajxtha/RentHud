Final Year Capstone Project

RentHub

A Digital Home Rent and Tenant Management Platform

Presented by Dipeshraj Shrestha
WHY
RENTHUB?
✕
No Reliable Discovery
Finding suitable rental properties in Nepal relies on word of mouth, Facebook groups, and basic classified sites with no map-based search or verified listings.
✕
No Trust or Transparency
Verbal agreements dominate. Tenants face arbitrary rent hikes, withheld deposits, and sudden evictions with no documented proof.
✕
Manual Application Process
Rental applications, landlord approvals, and lease agreements are handled through informal channels like phone calls, WhatsApp, and paper documents.
✕
Fragmented Tenancy Management
Rent records, maintenance requests, and dispute resolution are scattered across messages and notebooks with no centralized system.
Nepal needs a unified digital tenancy management platform, not just another property listing website.

Platform Capabilities
Advanced Features of RentHub
Implemented

Map-Based Property Discovery

Interactive map with PostGIS-powered location search. Browse properties by area with radius-based spatial queries and bounding circle visualization.

Separate Tenant & Landlord Roles

Dedicated dashboards for tenants and landlords. Each role has purpose-built workflows. Users can switch roles within a single account.

Digital Lease Agreements

Automated lease generation after application approval. Both tenant and landlord sign online. Second signature activates the tenancy.

Application Review Workflow

Tenants submit applications for specific property units. Landlords review, approve, or reject applications with structured status tracking.

Tenancy Lifecycle Management

Complete lifecycle: application → approval → pending signature → active tenancy → completion or early termination. Unit availability syncs automatically.

Tenancy Dispute Management

Both tenants and landlords can file disputes tied to their active tenancy. Provides structured documentation for contractual disagreements.

Property & Unit Management

Landlords create properties with location coordinates, manage multiple rentable units per property, and track unit availability status.

Property Photo Management

Upload multiple property photographs, set cover photos, and manage visual listings. Photos are tied directly to property records.

System Architecture & Engineering
Technologies Used
Full-Stack Ecosystem
Frontend & Web
  • React 18 & Vite: Single-page web application with fast HMR and component modularity.
  • TypeScript: Compile-time end-to-end type safety preventing runtime errors.
  • Leaflet / OSM: Interactive map property discovery and bounding circle overlays.
Backend Architecture
  • Node.js & Express: High-performance event-driven asynchronous server runtime.
  • Shared Contracts: Centralized Zod schemas and TypeScript interfaces in shared/.
  • REST & WebSockets: Structured REST endpoints plus real-time notification streams.
Database & Spatial Engine
  • PostgreSQL 16: ACID-compliant storage with partial unique indexes for tenancy integrity.
  • PostGIS: Spatial geosearch using ST_DWithin and GiST index acceleration.
  • Kysely Query Builder: Zero-overhead compile-time type-safe SQL query engine.
  • Redis: High-speed cache for session revocation, token blacklisting, and rate limiting.
Security & Infrastructure
  • Google OAuth 2.0: Streamlined authentication eliminating password storage risks.
  • JWT & Cookies: Short-lived access tokens with secure HttpOnly rotated refresh tokens.
  • Dual-Party Signatures: Digital signature audit trail activating formal lease agreements.
  • Docker & Compose: Containerized environments for consistent development and deployment.
